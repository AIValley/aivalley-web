# 多语言系统

AI Valley 支持 **9 种语言**，默认**简体中文**：

`zh`（简体中文）、`zh-TW`（繁体中文）、`en`（英语）、`ja`（日语）、`ru`（俄语）、`ko`（韩语）、`es`（西班牙语）、`fr`（法语）、`de`（德语）

## 两条文案链路

多语言分为两条相互独立的链路：

1. **界面文案**（按钮、标题、提示等）—— 由 `messages/*.ts` 字典提供。
2. **资源内容**（资源名称、简介、类型/分类/价格标签）—— 由数据库中的 `nameI18n` / `descI18n` 字段 + `lib/resources/meta.ts` 提供。

## 架构

- **路由**：`app/[locale]/…`，`locale` 是动态段。`proxy.ts` 会把无语言前缀的路径补成默认 `/zh`。
- **字典**：`lib/i18n.ts` 定义 `locales` 数组、`defaultLocale`，并导出 `getDictionary(locale)`；`messages/*.ts` 各提供一个 `Dictionary` 对象。
- **上下文**：`components/providers.tsx` 提供 `useDictionary()`（返回 `dict` + `locale`），供客户端组件取文案。
- **服务端**：页面通过 `getDictionary(locale)` 直接取 `dict`。

## 界面文案 vs 资源内容的取数

- 界面文案：`dict.xxx`（来自 `messages/*.ts`）。
- 资源内容：`localize(locale, en, zh, i18n?)`，定义在 `lib/resources/meta.ts`：

```ts
export function localize(locale, en, zh, i18n?) {
  if (locale === "zh") return zh;
  if (i18n?.[locale]) return i18n[locale];
  if (locale === "zh-TW") return zh; // 繁体缺省回退简体
  return en;
}
```

回退规则：简体直接返回 `zh`；有该语言专有翻译则用它；繁体缺省回退简体；其它语言回退英文。

## 如何新增一种语言

1. **新增字典**：在 `messages/` 下新建 `xx.ts`，内容结构完全对齐 `messages/zh.ts`（或 `en.ts`）。
2. **注册语言**：在 `lib/i18n.ts` 中：
   - 把语言码加入 `locales` 数组；
   - 在 `dictionaries` 中导入并挂载该字典。
3. **语言切换**：`components/locale-switcher.tsx` 的 `LABELS` 里加上该语言的显示名。
4. **类型/分类/价格标签**：在 `lib/resources/meta.ts` 的 `TYPE_META` / `CATEGORY_META` / `PRICING_META` 中，为每个条目补上 `xx` 字段。
5. **（可选）资源内容**：为现有资源补 `nameI18n` / `descI18n` 的 `xx` 翻译（见下）。

## 如何给资源补翻译

资源的名称/简介多语言存储在数据库的 `nameI18n` / `descI18n` 两个 JSON 字符串字段中。初始数据定义在 `lib/resources/seed-data.ts`，每条资源可选一个 `i18n` 块：

```ts
{
  nameEn: "Qwen",
  nameZh: "通义千问",
  descEn: "...",
  descZh: "...",
  i18n: {
    name: { "zh-TW": "通義千問" },   // 仅当该语言名称与英文不同时才需要
    desc: {
      "zh-TW": "阿里巴巴…",
      "ja": "アリババ…",
      "ru": "…",
      "ko": "…",
      "es": "…",
      "fr": "…",
      "de": "…",
    },
  },
}
```

修改后运行 `npm run db:seed` 重新填充即可生效。

> 提示：绝大多数品牌名（ChatGPT、Claude、Midjourney 等）在各语言里保持原文，因此 `name` 翻译通常只在中文来源资源（如 通义千问、可灵、智谱 GLM）或机构名（MIT 公开课、斯坦福 CS224N）上需要。

## 资源内容展示的调用点

以下组件/页面通过 `localize(..., resource.nameI18n / descI18n)` 展示资源名称与简介：

- `components/resource-card.tsx`（卡片）
- `app/[locale]/r/[id]/page.tsx`（详情页）
- `components/explore-client.tsx`（浏览排序）
- `components/admin-review.tsx`（审核）
- `components/dashboard/resources-client.tsx`、`submissions-client.tsx`（仪表板）

> 说明：用户新提交的资源默认只有中英文（`nameI18n`/`descI18n` 为空对象），管理员可在仪表板编辑补其它语言。

## 现状

- 界面文案：9 种语言齐全。
- 资源内容：69 条初始资源已全部翻译到 7 种语言（繁体中文、日、俄、韩、西、法、德）。
- 博客文章：仅中英双语（`titleEn/titleZh`、`contentEn/contentZh`），未扩展多语言。
